# Installation Guide

## macOS

1. Download `TimerPromodo-x.x.x.dmg` from the Releases page.
2. Open the `.dmg` and drag **TimerPromodo** into `Applications`.
3. On first launch, right-click the app and choose **Open** if Gatekeeper prompts you.

## Windows

1. Download `TimerPromodo-Setup-x.x.x.exe`.
2. Run the installer and pick an installation directory if prompted.
3. Launch from the Start Menu or desktop shortcut.

## Linux

### AppImage

```bash
chmod +x TimerPromodo-x.x.x.AppImage
./TimerPromodo-x.x.x.AppImage
```

### Debian / Ubuntu

```bash
sudo dpkg -i timerpromodo_x.x.x_amd64.deb
```

## Auto-updates

TimerPromodo checks for updates in the background. When a newer version exists, an in-app banner appears — you choose when to download and restart.

## Uninstall

- **macOS**: Drag the app from `Applications` to the Trash.
- **Windows**: Settings → Apps → Installed apps → TimerPromodo → Uninstall.
- **Linux (deb)**: `sudo dpkg -r timerpromodo`
